# AGENTS.md - Archived Agent Notes

Archived Agent Note triplets under the class directories are frozen historical snapshots, not current authority. Never edit, reformat, translate, repair, delete, or move a sealed artifact. Use an active Agent Note or current documentation for new decisions and facts.

An archival change may only relocate a complete English/Chinese/sidecar triplet, insert the identical `Archived: YYYY-MM-DD` line below both `Status: implemented` lines, re-record the sidecar, and repair or delete inbound links. Do not make any other content change during archival.

Use the repository's archive workflow and verifier when available. The normal verifier should reject changed or missing sealed artifacts, incomplete triplets, unknown class folders, and invalid archive metadata.
